    CCNA-Merksatz

    • IP-Adresse = welches Gerät
    • Subnetzmaske = welches Netzwerk
    • Netzwerkadresse = Anfang des Netzwerks
    • Broadcast = letzte Adresse des Netzwerks
    • Hostbereich = Adressen für Geräte
    • Default Gateway = Router für andere Netzwerke
    Alle Berechnungen laufen lokal im Browser — keine Daten werden übertragen.
