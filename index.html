CCNA Subnetting Lab

Ändere eine Zahl, klicke auf ein Bit oder ein Subnetz — und sieh sofort, was im Netzwerk passiert, inklusive Erklärung, warum.

Hauptfunktion

Adressraum-Visualisierer

Jedes Oktett als Raster aus 256 möglichen Werten. Blau = durch das Präfix festgelegt, Orange = frei für Hosts/Subnetze. Tippe auf ein Feld, um das Oktett auf diesen Wert zu setzen.

/

Subnetz-Rechner

IP und Präfix eingeben — oder direkt auf die Bits klicken. Zeile IP: Bit umschalten. Zeile M (Maske): Präfix verschieben. Zeile N zeigt das Ergebnis von IP AND Maske = Netzwerkadresse.

/

Subnetzmasken-Vergleich

Dieselbe Adresse bei immer längeren Masken: jede Stufe halbiert die Netze. Tippe auf ein Segment, um die Adresse in dieses Subnetz zu verschieben.

/

Sind diese Geräte im selben Netz?

Entscheidend ist nur, ob die Netzwerkbits übereinstimmen. Rot markierte Bits unterscheiden sich innerhalb des Präfixes.

/

IP-Konfiguration validieren

Prüft eine vollständige Host-Konfiguration Schritt für Schritt.

/

    Subnetz-Teiler

    Teile ein Netz in gleich große Subnetze — nach Anzahl der Netze oder nach benötigten Hosts. Mit VLSM bekommt jedes Netz genau die Größe, die es braucht. Tippe auf eine Zeile, um sie im Rechner zu öffnen.

    /

    CIDR-Tabelle

    Je länger das Präfix, desto mehr Netzwerkbits — desto weniger Platz für Hosts. Tippe auf eine Zeile oder gib ein, wie viele Hosts du brauchst.

    Trainer

    Beantworte Fragen wie in der CCNA-Prüfung — mit Erklärung nach jeder Antwort. Tastatur: 1–4 antworten, Enter weiter.

    Spickzettel

    • IP-Adresse = welches Gerät
    • Subnetzmaske = welches Netzwerk
    • Netzwerkadresse = erste Adresse (alle Hostbits 0)
    • Broadcast = letzte Adresse (alle Hostbits 1)
    • Hostbereich = alles dazwischen
    • Default Gateway = Router ins andere Netz, muss im eigenen Subnetz liegen
    • Hosts = 2Hostbits − 2
    • Blockgröße = 256 − Maskenwert im „interessanten“ Oktett
