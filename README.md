# [learn-subnetting visually](https://vsvito420.github.io/learn-subnetting/index.html)

Interaktives CCNA-Subnetting-Lab im Browser, ohne Build und ohne Server, optimiert für Desktop und Handy.

- **Adressraum-Visualisierer**: jedes Oktett als 16×16-Raster, Felder anklickbar
- **Subnetz-Rechner**: klickbare Bits (IP AND Maske = Netz), Nachbarnetze, Link zum Teilen (`?ip=…&cidr=…`)
- **Masken-Vergleich**: wie Subnetze ineinander verschachtelt sind
- **Selbes Netz?** und **Konfig prüfen** mit Bit-Vergleich und Zahlenstrahl
- **Subnetz-Teiler**: nach Anzahl Netze, Hosts pro Netz oder **VLSM**
- **CIDR-Tabelle** mit Blockgröße und Host-Bedarf
- **Trainer**: Adresstyp, Netz/Broadcast, Hosts, Masken, Binär, mit Statistik und Tastatursteuerung
- Hell-/Dunkel-Modus (automatisch oder manuell)
